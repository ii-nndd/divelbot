# 👑 بوت نوفا الملكية + لوحة التحكم

بوت ديسكورد عربي (Nova) مع لوحة تحكم ويب كاملة ونظام مستويات/اقتصاد/تذاكر/سجن/فخ/ترحيب.

---

## المكوّنات

| الملف | الوظيفة |
|---|---|
| `index.js` | القلب: العميل، الأوامر، الفويس 24/7، معالج الرسائل، سيرفر الويب |
| `dashboard.js` | لوحة التحكم `/dashboard` (OAuth2 ديسكورد) + مسارات API |
| `panel.js` | لوحة تحرير الردود `/panel` (كلمة مرور) |
| `botcontrol.js` | تفعيل/تعطيل البوت لكل روم + الروم الصوتي (يعدله الداشبورد فوراً) |
| `colors.js` | رتب الألوان: بانل بروم مخصص (Embed + قائمة اختيار) + إدارة الألوان + إزالة شاملة من كل الأعضاء |
| `store.js` | تخزين JSON محلي + نسخة دائمة MongoDB |
| `points.js` / `levels.js` | النقاط والمستويات (كتابي/صوتي/إجمالي) + بطاقات Canvas |
| `cards.js` | رسم بطاقات الرتبة والمتصدرين (Canvas) |
| `admin.js` / `nlcommands.js` | أوامر الإدارة بالسلاش وبالكلام الطبيعي |
| `economy.js` `games.js` `gamedata.js` `giveaway.js` `selfroles.js` `tickets.js` `jail.js` `trap.js` `welcome.js` `replies*.js` | بقية الأنظمة |

## التشغيل محلياً

```bash
npm install
copy .env.example .env     # ثم عبّي القيم
npm start
```

- لوحة التحكم: http://localhost:3000/dashboard
- لوحة الردود: http://localhost:3000/panel
- فحص الصحة: http://localhost:3000/health

يتطلب Node.js 20 أو أحدث.

**أسهل طريقة على ويندوز:** شغّل ملف **`تشغيل محلي.bat`** بضغطة مزدوجة — يثبّت الحزم أول مرة، ويسوي لك `.env` ويفتحه عشان تحط التوكن، وبعدها يشغّل البوت. (خلّ النافذة مفتوحة؛ عشان يبقى البوت أونلاين 24/7 لازم الجهاز يبقى شغال.)

## البقاء أونلاين 24/7

البوت مصمم بحيث **ما يصير أوفلاين ولا يتسكّر**:

- **نبض بقاء (Keep-Alive)**: يفتح `/health` كل 5 دقايق عشان استضافة Render المجانية ما تنيّم الخدمة.- **إعادة اتصال تلقائية**: لو انقطع الاتصال أو انتهت صلاحية الجلسة يعيد تسجيل الدخول لحاله، ومع تكرار الفشل يباعد المحاولات (2 → 32 دقيقة) بدل ما يعتمد على خراب.
- **منع الكراش**: `unhandledRejection` و`uncaughtException` و`client error` تتسجل فقط ولا توقف العملية.
- **فويس مستمر**: حارس كل دقيقة يرجّع البوت للروم الصوتي (يشتغل فقط بعد تسجيل الدخول).
- **الحالة دائمة أونلاين**: الحالة تُضبط على `online` عند كل اتصال حتى ما يبيّن أوفلاين.

⚠️ **مهم (خطة Render المجانية):** إبقاء الخدمة صاحية 24/7 يستهلك ~**744 ساعة** من أصل **750 ساعة مجانية** في الشهر للحساب كامل. لو خلصت الساعات، Render **يوقف كل خدماتك المجانية لحد أول الشهر الجاي** وتطلع لك صفحة `This service has been suspended`. عشان توفر الساعات حط `KEEPALIVE=0` (الخدمة تنام لو ما فيه زيارات — بس البوت يطلع أوفلاين وقت النوم). للحل الدائم: رقّي الخدمة لخطة مدفوعة، أو شغّل البوت من جهازك بملف `تشغيل محلي.bat`.

للتحقق: `curl https://<رابط-النشر>/health` لازم يرجع `200` مع `bot=online`.

## رتب الألوان (Color Roles)

قسم «رتب الألوان» في لوحة التحكم يدير نظام ألوان كامل:

- **روم قائمة الألوان**: تحدّده من اللوحة، وتضيف عنوان ووصف للبانل، وتتحكم بإرساله من جديد بنقرة.
- **صورة الألوان (Canvas)**: تُولَّد صورة PNG بمكتبة `@napi-rs/canvas` (`colorimage.js`) بخلفية غامقة هوية نوفا + شبكة دوائر بأكواد الألوان ورقم كل لون (1، 2، 3…) تحت دائرته، وتنزل مع رسالة البانل كصورة رئيسية للمّ Embed. وزر «🖼️ إعادة توليد صورة الألوان وإرسالها» + معاينة مباشرة للصورة باللوحة.
- **الألوان الصريحة الجاهزة (14 لون)**: زر «🎨 تجهيز الألوان الصريحة» ينشئ الرتب بنفس الأكواد بالضبط (أسود `#010101` … عنابي `#800020`) ويصحّح كود أي رتبة موجودة بنفس الاسم، وخيار لحذف الألوان القديمة. والبوت يسويها **تلقائياً** أول اتصال لو القائمة فاضية.
- **إدارة الألوان**: إنشاء رتبة لون، ربط رتبة موجودة، تغيير الاسم/اللون، إزالة من القائمة أو حذف الرتبة نهائياً — والتحديث ينزل بالسيرفر والبانل فوراً.
- **قائمة الاختيار**: أرقام فقط (1، 2، 3…) مطابقة لأرقام الصورة؛ العضو يختار رقمه فياخذ الرتبة وتنشال عنه باقي ألوان السيرفر (لون واحد لكل عضو).
- **حتى 125 لون**: لو زادت الألوان عن 25 تنقسم تلقائياً على **5 قوائم** بنفس الرسالة (25 خيار لكل قائمة = حد ديسكورد).
- **إزالة شاملة**: زر يسحب كل رتب الألوان من جميع الأعضاء (بالخلفية مع شريط تقدم)، لو بغيت توزيع الألوان من جديد.
- **من ديسكورد مباشرة**: `/ألوان` أو «**يا عبد الألوان**» → البوت يولّد صورة الألوان من جديد، يحدّث البانل بالروم، ويرسل الصورة مع رده. وكل إقلاع للبوت يحدّث البانل بالصورة تلقائياً.

متطلبات التشغيل: صلاحية **Manage Roles** للبوت، ورتبة البوت **أعلى** من رتب الألوان. البانل يرجع تلقائياً لو انحذف.

## متغيرات البيئة

| المتغير | الوصف | إلزامي |
|---|---|---|
| `DISCORD_TOKEN` | توكن البوت | ✅ |
| `DISCORD_CLIENT_ID` | OAuth2 Client ID | للوحة |
| `DISCORD_CLIENT_SECRET` | OAuth2 Client Secret | للوحة |
| `SESSION_SECRET` | مفتاح توقيع الجلسات | للوحة |
| `PUBLIC_URL` / `RENDER_EXTERNAL_URL` | رابط النشر (Redirect URI) | للوحة |
| `MONGODB_URI` / `MONGODB_DB` | التخزين الدائم للنقاط والإعدادات | مستحسن |
| `ADMIN_PASSWORD` | كلمة مرور `/panel` | للوحة الردود |
| `MEMBERS_INTENT` | `1` لتفعيل البحث بالاسم والترحيب | اختياري |
| `PORT`, `DATA_DIR` | منفذ الويب ومجلد البيانات | اختياري |

## إعداد Discord Developer Portal

1. **Bot** → انسخ التوكن إلى `DISCORD_TOKEN`.
2. **Privileged Gateway Intents** → فعّل:
   - `SERVER MEMBERS INTENT` (للترحيب وصفحة الأعضاء والبحث بالاسم)
   - `MESSAGE CONTENT INTENT` (لأوامر الكلام الطبيعي والردود)
3. **OAuth2 → Redirects** → أضف:
   `https://<رابط-النشر>/auth/callback`
4. لوحة التحكم محصورة تلقائياً على حسابي ارثر وإيدا (المعرّفان في `CONFIG` داخل `index.js`).

## النشر على Render

1. أنشئ **Web Service** جديد واربطه بمستودع GitHub هذا.
2. Build: `npm install` — Start: `npm start`.
3. أضف متغيرات البيئة من الجدول أعلاه (من **Environment**).
4. فعّل **Auto-Deploy**: أي `git push` على الفرع الرئيسي ينشر تلقائياً.
5. أضف قاعدة بيانات MongoDB (Atlas أو Render) وحطّ رابطها في `MONGODB_URI` — بدونها تضيع التعديلات عند كل إعادة تشغيل.

> اختياري: ملف `render.yaml` موجود كـ **Blueprint** — لو بغيت تنشئ الخدمة من جديد بنقرة وحدة (Render ➜ New ➜ Blueprint ➜ اختر المستودع)، وراح يطلب منك القيم السرية بنفسه.

### لو طلعت لك صفحة `This service has been suspended`

هذي رسالة من **Render نفسه** (مو من البوت)، ومعناها إن الخدمة موقوفة من عندهم — أشهر سببين:

1. **خلصت الـ750 ساعة المجانية** للحساب هذا الشهر (إبقاء البوت أونلاين 24/7 يآكل ~744 ساعة لحاله). الحل: تنتظر أول الشهر الجاي (الساعات ترجع 750)، أو ترقّي الخدمة لخطة مدفوعة، أو تحط `KEEPALIVE=0` عشان توفر الساعات.
2. **تجاوزت حصة البيانات (Bandwidth)** وما فيه طريقة دفع مسجّلة → Render يوقف الخدمات المجانية لبقية الشهر.

شنو تسوي: افتح [Render Dashboard](https://dashboard.render.com/billing#included-usage) ← **Billing ➜ Monthly Included Usage** وشوف كم استهلكت، و**Notifications**/بريدك الإلكتروني (Render يرسل تنبيه قبل التجاوز وبعده). بعدها إمّا **Upgrade** الخدمة (Settings ➜ Instance Type) أو انتظر التجديد، وشغّل البوت من جهازك للمدة هذي بـ `تشغيل محلي.bat`.
