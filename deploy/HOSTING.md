## 🅰️ المسار الأول — حساب Render جديد (الأسرع: كل شي يشتغل مثل قبل)

**ليش «حساب جديد» مو نفس الحساب؟** لأن الحساب القديم استهلك حصته، والحصة ترجع **١ نوفمبر**. وحساب جديد يعطيك ٧٥٠ ساعة جديدة من اليوم.

> ⚠️ **لا تسجل دخول بحساب GitHub!** Render يعرفك ويدخّلك على الحساب القديم.
> توثيق Render: «If you already have a Render account that matches your Git provider account's primary email address, Render logs you in to the existing account automatically.»
> ✅ سجّل بـ **إيميل جديد + كلمة مرور**، وبعدها اربط GitHub **للنشر فقط** (مسموح: «You can use a Git provider for deployment without using it for login»).

### ١) اجمع القيم السرية (قبل أي شي)
هذي القيم موجودة أصلاً في خدمتك القديمة — انسخها من Render القديم ← اختر خدمة `novabot` ← **Environment**:

| المتغير | من وين تجيبه |
|---|---|
| `DISCORD_TOKEN` | Render القديم (Environment) · أو Discord Developer Portal ← Bot ← Reset Token |
| `DISCORD_CLIENT_ID` | Discord Developer Portal ← General Information ← Application ID |
| `DISCORD_CLIENT_SECRET` | Discord Developer Portal ← OAuth2 ← Client Secret (Reset إن ما تعرفه) |
| `ADMIN_PASSWORD` | اللي كنت تستخدمه لـ`/panel` (أو اختر واحد جديد) |
| `MONGODB_URI` | نفسه اللي كان عندك · **وإن ما كان موجود → سوّه من القسم ج تحت** (مهم عشان البيانات ما تضيع) |

> 🔒 **لا ترسل هذي القيم في المحادثة** — تنحط بس في لوحة Render.

### ٢) سوّ الحساب الجديد
1. افتح <https://dashboard.render.com/register>
2. **Sign up with email** (إيميل ثاني غير إيميل حسابك الحالي) + كلمة مرور.
3. أكّد الإيميل.

### ٣) أنشئ الخدمة من الـBlueprint
1. من اللوحة: **New ➜ Blueprint**.
2. اربط مستودع `ii-nndd/novabot` (المستودع عام).
   - إن رفض GitHub لأنه مربوط بحسابك الثاني: اختر **Public Git Repository** والصق `https://github.com/ii-nndd/novabot` بدال ربط الحساب.
3. Render يقرأ `render.yaml` جاهز، وراح يطلب منك القيم اللي عليها `sync: false` → عبّيها من جدول الخطوة ١.
   - `SESSION_SECRET` يولّده Render تلقائياً ✅
   - `KEEPALIVE` لازم يبقى **`1`** (وإلا الخدمة تنام بعد ١٥ دقيقة سكون والبوت يطلع أوفلاين).
4. **Apply / Create** وانتظر النشر ~٣ دقايق.

### ٤) تأكد إنه شغال
```
https://<اسم-خدمتك>.onrender.com/health
```
لازم يرجع **200** والنص فيه **`bot=online`**. لو `connecting` انتظر دقيقة وحدّث.

### ٥) اللوحة تعمل؟ حدّث Redirect URI
1. خذ رابطك من Render (فوق رأس الخدمة).
2. Discord Developer Portal ← تطبيق البوت ← **OAuth2** ← **Redirects** ← **Add Redirect**:
   ```
   https://<اسم-خدمتك>.onrender.com/auth/callback
   ```
   > لا تحذف القديم (`divelbot.onrender.com/auth/callback`) — خلّه، ما يضر.
3. افتح `https://<اسم-خدمتك>.onrender.com/dashboard` ← «تسجيل الدخول بحساب ديسكورد».

نقطة مهمة: اللوحة تقرأ رابطها من `RENDER_EXTERNAL_URL` اللي يحطه Render تلقائياً — يعني **ما تحتاج تضبط `PUBLIC_URL`**.

### ٦) النشر التلقائي (push ➜ نشر)
- لو ربطت المستودع كـBlueprint: ✅ مفعّل (`autoDeploy: true` في `render.yaml`).
- لو نشرت بـ**Public Git Repository** (بدون ربط GitHub): Auto-Deploy ما يشتغل. الحل: Render ← الخدمة ← **Settings ➜ Deploy Hook** انسخ الرابط، وأرسله لنا (ما هو سر خطير، بس الأفضل نحطه في GitHub Secrets) → نضيف لك GitHub Action ينشر عند كل push.

### ٧) 🚫 ممنوعات الحساب الجديد (هذي اللي أوقفت الحساب القديم)
1. **لا تضيف أي خدمة ثانية مجانية** على نفس الحساب. ٧٥٠ ساعة للحساب كله، والبوت ياكل ~٧٤٤.
   - السبب الأرجح لإيقافك القديم: خدمة ثانية على نفس الحساب (خدمتين × ~٣٨٤ ساعة = ٧٦٨ > ٧٥٠).
2. **لا تخلي خدمة Render القديمة ترجع** — ١ نوفمبر بترجع وتشتغل مع الجديدة = **بوتين يردون مرتين**. احذفها (شوف «قائمة التحقق» تحت).

## 🅱️ المسار الثاني — HeavenCloud (الأدوم: بلا حد ساعات، بلا بطاقة)

**المواصفات المثبّتة:** ٧١٥ MB رام · ١ GB قرص · ٧٥٪ معالج · ٢٤/٧ بلا نوم · Nuremberg (ألمانيا) أو Miami (أمريكا) · Pterodactyl · **بدون بطاقة**.
**المقابل:** تجديد بنقرة كل **٧ أيام** + لازم تدخل سيرفرهم بالديسكورد.

> بديل مماثل: **Wispbyte** (`wispbyte.com`) — ٥١٢ MB رام، تسجيل دخول كل أسبوعين، بلا إعلانات، «النسخ ما تنحذف». نفس الخطوات بالضبط لأن الاثنين Pterodactyl.

### ١) اطلب السيرفر
1. ادخل سيرفر HeavenCloud بالديسكورد: <https://discord.gg/getvps> (إلزامي للحساب المجاني).
2. افتح اللوحة <https://control.heavencloud.in> ← سجّل ← **Create Server**.
3. اختر: المنطقة (Nuremberg أو Miami) + الخطة **Free** + البيئة **Node.js** (Node 20 أو أحدث).

### ٢) ارفع الكود
أسهل طريقة (بلا تعقيد):
1. من GitHub: `Code ➜ Download ZIP` لمستودع `novabot` (حجمه ~٢ MB، لا يحتوي `node_modules`).
2. في اللوحة: **File Manager** ← **Upload** ← ارفع الـZIP ← **Extract** في جذر السيرفر.

أو من **Console**:
```bash
git clone https://github.com/ii-nndd/novabot.git .
```

### ٣) أمر التشغيل
في اللوحة ← **Startup** ← خانة **Startup Command**، حط:
```bash
npm install --omit=dev && node index.js
```
> `--omit=dev` مهم: المشروع ما فيه حزم تطوير، بس يمنع أي تثبيت زايد ويتسارع الإقلاع.

### ٤) متغيرات البيئة
اللوحة ← **Startup ➜ Variables** (كل واحد مفتاح/قيمة):

| المفتاح | القيمة |
|---|---|
| `DISCORD_TOKEN` | توكن البوت (السر) |
| `DISCORD_CLIENT_ID` | Application ID |
| `DISCORD_CLIENT_SECRET` | OAuth2 Client Secret |
| `SESSION_SECRET` | نص عشوائي طويل (٤٠ حرف) |
| `ADMIN_PASSWORD` | كلمة مرور `/panel` |
| `MONGODB_URI` | رابط Atlas (القسم ج) |
| `MONGODB_DB` | `nova` |
| `MEMBERS_INTENT` | `1` |
| `KEEPALIVE` | **`0`** (ما نحتاج نبض بقاء هنا — يوفّر موارد) |
| `TUNNEL` | **`1`** (يفتح رابط HTTPS عام للوحة عبر نفق Cloudflare — بدون حساب وبدون دومين) |
| `PORT` | `3000` |
| `DATA_DIR` | `/home/container/data` |

### ٥) شغّل وتابع
اضغط **Start** وتابع **Console** حتى تشوف `🌐 Web server on port 3000` و`✅ البوت جاهز`.
> ملاحظة: `@napi-rs/canvas` عنده prebuild لـ`linux-x64-gnu` → يشتغل بدون أي تعديل (تحققنا من npm).

### ٦) اللوحة — نفق Cloudflare التلقائي ✅ (مبني ومُختبر)
لوحات Pterodactyl المجانية **ما تعطي رابط HTTPS عام**، واللوحة تحتاج HTTPS عشان Discord يقبل `redirect_uri`. الحل مبني في `tunnel.js`:
1. البوت أول ما يشتغل (لو `TUNNEL=1`) **ينزّل `cloudflared`** الرسمي (مجاني · بلا حساب · بلا دومين · بلا بطاقة) ويشغّله نفق سريع على منفذه.
2. يطلع رابط مثل `https://xxxx.trycloudflare.com` ويحطه في `PUBLIC_URL` تلقائياً.
3. **يسجّل `redirect_uri` عند Discord بنفسه** عبر `PATCH /applications/@me` → ما تحتاج تلمس Developer Portal أبداً.
4. ويرسل لك الرابط **برسالة خاصة بالديسكورد**، ويطبعه في الـConsole: `🌉 رابط اللوحة العام: https://...`

افتح `<الرابط>/dashboard` ← سجّل دخولك ← يشتغل ✅
- الرابط **يتغير كل إعادة تشغيل** (طبيعة النفق المجاني) والبوت يعيد تسجيله تلقائياً — ما فيه أي شي تسويه.
- أول ما يطلع الرابط، **قد يحتاج دقيقة أو دقيقتين** لين يفتح (انتشار DNS + كاش سلبي). البوت يطبع `✅ النفق جاهز` لما يتأكد.
- ⚠️ **لو ما فتح الرابط:** الأسباب المجرّبة عندك — **VPN (ProtonVPN) شغال**، أو الشبكة تحجب `trycloudflare`، أو كاش DNS سلبي.
  الحل: طفّي الـVPN، أو افتح الرابط من الجوال، أو غيّر DNS إلى `1.1.1.1`.
- لو فشل النفق: **البوت يكمل شغال عادي**، بس اللوحة بلا رابط عام (شوف الـConsole).
- لإلغاء النفق: `TUNNEL=0`.

### ٧) تجديد كل ٧ أيام
اللوحة ← زر **Renew** (يطلع قبل الموعد بـ٤٨ ساعة، وفيه سماح ٢٤ ساعة). لو ما جدّدت: السيرفر يوقف، وبعد يومين ينحذف (والملفات كانت تبقى — بس لا تعتمد).

## 🅾️ القسم ج — MongoDB Atlas مجاني للأبد (بدون بطاقة) ⭐ مهم

**ليش؟** بدون قاعدة بيانات، كل إعادة نشر/تحديث تعني **ضياع الألوان والردود والمستويات** (تخزين الاستضافة مؤقت). Atlas يعطيك ٥١٢ MB مجاناً للأبد بدون بطاقة، والبيانات تبقى معك مهما انتقلت بين الاستضافات.

1. افتح <https://www.mongodb.com/cloud/atlas/register> وسجّل (إيميل أو Google).
2. **Build a Database ➜ M0 FREE** (ما يسأل عن بطاقة). اختر أقرب منطقة (مثلاً Frankfurt أو Mumbai).
3. **Network Access ➜ Add IP Address ➜ Allow Access from Anywhere** (`0.0.0.0/0`) — لازم، لأن الاستضافة تتغير.
4. **Database Access ➜ Add New Database User** ← اسم مستخدم + كلمة مرور **قوية بلا رموز خاصة** (احفظها).
5. **Connect ➜ Drivers ➜ Node.js** ← انسخ الرابط، وشكله:
   ```
   mongodb+srv://<user>:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
   ```
6. حدّد قاعدة البيانات: إما تضيفها في الرابط قبل `?` → `/nova`، أو تضبط `MONGODB_DB=nova` في الاستضافة (الأسهل).
7. حطّه في `MONGODB_URI` عند الاستضافة، وأعد التشغيل.
8. تحقق: افتح اللوحة ← «المستويات» ← لازم تطلع بيانات (لو كلها أصفار فالاتصال ما ضبط).

**تنبيه أمني:** رمز `MONGODB_URI` سر → في لوحة الاستضافة فقط، ولا يُكتب في Git ولا في المحادثة.

## 🧯 استكشاف الأخطاء السريع

| المشكلة | السبب والحل |
|---|---|
| `503 Service Suspended` | الحساب خلصت ساعاته → ١ الشهر الجاي أو حساب جديد. مو خطأ بالكود. |
| البوت `connecting` وما يتصل | توكن غلط، أو **نسختين شغالين بنفس التوكن** (احذف القديمة)، أو Server Members Intent مطلوب. |
| «فشل تسجيل الدخول (تأكد من Redirect URI)» | الـRedirect URI في موقع المطورين لازم يطابق رابط الموقع **حرف بحرف** (بلا `/` زايدة). |
| `⛔ هذا الحساب غير مسموح له بدخول اللوحة` | حسابك مو Arthur ولا الإيميل المخصص — هذي حماية مقصودة. |
| المستويات/النقاط كلها أصفار | `MONGODB_URI` مو مضبوط أو IP غير مسموح في Atlas. |
| صورة الألوان ما تطلع | فشل الكانفس → البانل يرجع تلقائياً لقائمة نصية. تأكد `npm install` كامل على Linux. |
| البوت يرد مرتين على كل رسالة | **فيه نسختين شغالين** — احذف وحدة (Render القديمة عادة). |
